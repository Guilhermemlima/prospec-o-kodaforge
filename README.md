# CRM de prospecção · Koda Forge

CRM em um único arquivo HTML com os 340 leads de Guarapuava (fonte: Google Maps).

**Como usar:** abra `index.html` no Chrome (ou o link da Vercel). Clique numa empresa → "Enviar no WhatsApp" abre a conversa com a mensagem pronta; é só apertar Enter. O status, o histórico e o próximo follow-up são atualizados automaticamente.

O progresso fica salvo no navegador (localStorage). Faça backup em "Mensagens e ajustes".
